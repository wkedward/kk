# XMedia - 媒体服务

xmedia 提供媒体文件处理、转码、水印等功能。

## 功能特性

- 媒体文件上传
- 视频转码
- 图片水印
- 媒体管理

## 架构

```
xmedia/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
