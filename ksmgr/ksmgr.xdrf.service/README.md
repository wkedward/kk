# XDRF - 动态表单报表服务

xdrf 提供动态表单和动态报表功能。

## 功能特性

- 动态表单设计
- 表单数据收集
- 动态报表设计
- 报表生成与导出

## 架构

```
xdrf/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
