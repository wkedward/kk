# XBase - 基础服务

xbase 提供数据字典、配置管理、权限管理、授时服务等基础功能。

## 功能特性

- 数据字典管理
- 配置管理
- 权限管理
- 授时服务

## 架构

```
xbase/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
