# XRes - 资源服务

xres 提供资源管理、静态资源托管等功能。

## 功能特性

- 资源管理
- 静态资源托管
- CDN 加速

## 架构

```
xres/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
