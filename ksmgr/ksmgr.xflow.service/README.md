# XFlow - 工作流服务

xflow 提供工作流定义、流程编排、流程实例管理等功能。

## 功能特性

- 工作流定义
- 流程编排
- 流程实例管理
- 任务分配

## 架构

```
xflow/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
