# XLog - 日志服务

xlog 提供日志收集、存储、分析和查询功能。

## 功能特性

- 日志收集
- 日志存储
- 日志分析
- 日志查询

## 架构

```
xlog/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
