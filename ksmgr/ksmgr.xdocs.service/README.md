# XDocs - 文档服务

xdocs 提供文档管理、在线协作、版本控制等功能。

## 功能特性

- 文档管理
- 在线协作
- 版本控制
- 文档预览

## 架构

```
xdocs/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
