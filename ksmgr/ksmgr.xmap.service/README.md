# XMap - 地图服务

xmap 提供地图数据管理、地理编码等功能。

## 功能特性

- 地图数据管理
- 地理编码
- 路径规划

## 架构

```
xmap/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
