# XAPI - API 网关服务

xapi 提供 API 网关、路由、限流等功能。

## 功能特性

- API 网关
- 路由管理
- 请求限流
- API 监控

## 架构

```
xapi/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
