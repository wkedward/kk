# XBRST - 业务规则服务

xbrst 提供业务规则定义、规则引擎等功能。

## 功能特性

- 业务规则定义
- 规则引擎
- 规则测试与验证

## 架构

```
xbrst/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
