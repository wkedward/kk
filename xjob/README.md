# XJob - 任务调度服务

xjob 提供任务调度、定时任务、任务监控等功能。

## 功能特性

- 任务调度
- 定时任务
- 任务监控
- 任务日志

## 架构

```
xjob/
├── src/
│   ├── controllers/    # API 控制器
│   ├── models/         # 数据模型
│   ├── services/       # 业务逻辑
│   └── utils/          # 工具类
├── config/             # 配置文件
├── data/               # 数据目录
└── public/             # 依赖库
```
